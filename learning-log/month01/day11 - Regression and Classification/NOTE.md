
# Day 31 — Regression and Classification

## 1. What is Regression?
-> Regression is the type of supervised ML  which predicts the continuous numerical target.

## 2. Five Regression Problems
1. House Price Prediction <br>
2. Student Marks Predictin <br>
3. Gold Price Prediction <br>
4. Salary Prediction <br>
5. Car Price Prediction <br>

## 3. What is Classification?
-> Classification is the type of supervised ML which predicts the discrete class or category.

## 4. Five Classification Problems
1. Email spam or not
2. cpu overheated or normal
3. Bank should give loan or not
4. Cat or Dog
5. sensor reading -> safe or not

## 5. Regression vs Classification
Evaluation Matrix:: MSE,MAE,MSE for regression, and R2 score , F1 score, accuracy, recall  for Classification

## 6. Linear Regression
Explain:
- Slope:Change in predicted target for a one-unit increase in the feature 
- Intercept:Predicted target when all input features are zero
- Input: features given to the model
- Output: the actual target variable
- Prediction: the output of the model

## 7. Decision Boundary
-> Decision Boundary is the line/curve which splits the feature space for classification predicition.
